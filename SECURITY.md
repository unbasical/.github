# Security policy

Please report security vulnerabilities in any unbasical repository privately.
Do not open a public issue, discussion, or pull request.

## How to report

1. Open the affected repository on GitHub.
2. Go to the **Security** tab.
3. Choose **Report a vulnerability** and describe the issue, the affected
   versions, and the steps to reproduce it.

The report stays private between you and the repository maintainers. We reply
in the advisory and coordinate a fix and disclosure with you there.
